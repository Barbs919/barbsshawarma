# BARB'S SHAWARMA AND GRILLS — Professional Nigerian Food Ordering Starter

This v2 is designed to feel like a modern Nigerian restaurant ordering site:
- strong mobile-first layout
- Nigerian naira pricing
- WhatsApp ordering
- delivery / pickup
- Pay on Delivery
- Paystack-ready setting
- search and menu categories
- professional hero, promo and trust sections
- admin dashboard for changing menu prices/descriptions
- order records stored locally in the browser for this starter

Admin page: `admin_fixed.html`

IMPORTANT:
This is a front-end starter. Before public launch, replace the demo admin login with secure server authentication, put orders in a real database, and connect Paystack through a secure backend that verifies transactions. Never expose a Paystack secret key in browser code.
